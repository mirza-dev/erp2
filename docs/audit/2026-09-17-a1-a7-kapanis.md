### 4.1 — E2E'nin bulduğu ürün kusuru: `revalidateTag(tag, "max")` bayat okuma

smoke (a) ilk koşumda düştü: gönderdikten sonra teklif detayı **"Taslak" + "Gönder"**
gösteriyordu; PO detayı onaydan sonra "Onaylandı" göstermiyordu. Kaynak
`node_modules/next/dist/server/...`'dan okundu (Next 16.3.3):

- `revalidateTag(tag, "max")` = **stale-while-revalidate**: manifest'e `stale = now`,
  `expired = now + max.expire` yazar; `areTagsExpired` `expiredAt <= now && expiredAt > entry.timestamp`
  → false → **bayat girdi bir kez daha servis edilir**.
- Tek argümanlı `revalidateTag(tag)` = anında ama deprecated uyarısı; `updateTag` route
  handler'da fırlatır.
- **Düzeltme:** `next.config.ts` → `cacheLife: { immediate: { stale: 0, revalidate: 0, expire: 0 } }`
  (profiller varsayılanlarla birleşir, `workStore.cacheLifeProfiles`tan okunur, `cacheComponents`ten bağımsız)
  + **48 kaynak dosyada** `revalidateTag(x, "immediate")` (13 test dosyası hizalandı).
- **Kapı:** `gate/cache-invalidation-profile` (3): profil `expire: 0` · ≥60 çağrı · her `revalidateTag` `"immediate"` ile biter. 2/2 kırmızı-kanıtlı.
- **Geriye dönük açıklama:** 2026-08-30'un `waitForInList` "eventual consistency" workaround'u bu kusurun ürünüydü.
